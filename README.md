# Real-Time Chat Application

A full-stack Real-Time Chat Application developed using Java, Spring Boot, Hibernate/JPA, MySQL, and WebSocket technology. The application enables users to communicate through instant messaging with persistent message storage and a responsive chat interface.

## Features

- User registration and login
- Secure authentication and authorization
- Real-time messaging using WebSocket
- Persistent chat history stored in MySQL
- User and conversation management
- Responsive and user-friendly interface
- RESTful API development
- Database integration using Hibernate/JPA

## Technologies Used

- **Backend:** Java, Spring Boot, Spring Security
- **Real-Time Communication:** WebSocket, STOMP
- **ORM:** Hibernate, Spring Data JPA
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## Project Objective

The objective of this project is to develop a real-time messaging application while gaining practical experience in Java full-stack development, REST APIs, database management, authentication, and WebSocket-based communication.

## Future Enhancements

- Group chat functionality
- Online/offline status
- Typing indicators
- Message delivery and read receipts
- Profile pictures and emoji support
- Message search and pagination

## How to Run

1. Clone this repository.
2. Configure your MySQL database.
3. Update the database credentials in `application.properties`.
4. Build the project using Maven.
5. Run the Spring Boot application.
6. Open the frontend in your browser and test the application.
